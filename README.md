# AMD-PRESTA ERP

ERP pour AMD-PRESTA - Maintenance technique et multi-services (Maroc).

## Installation locale

Lancer Docker Desktop, puis dans ce dossier executer :

    docker compose up -d --build

Puis ouvrir : http://localhost

## Comptes par defaut

- Admin : admin@amd-presta.ma / admin123
- Manager : manager@amd-presta.ma / admin123
- Technicien : tech@amd-presta.ma / admin123

## Arreter

    docker compose down
